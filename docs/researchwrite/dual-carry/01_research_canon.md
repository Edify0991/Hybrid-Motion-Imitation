# 研究事实与约束

## 文献事实

1. GfR论文2602.20375研究参考引导与目标RL共享策略，主要展示parkour；当前仓库搬箱是非官方扩展，不能称其结果为原论文官方搬箱基线。https://arxiv.org/html/2602.20375v1
2. SkillMimic使用随机参考帧初始化与高层技能组合；V2进一步提出邻域初始化、STF和STG，不能把“加随机扰动”本身作为独立新贡献。https://openaccess.thecvf.com/content/CVPR2025/html/Wang_SkillMimic_Learning_Basketball_Interaction_Skills_from_Demonstrations_CVPR_2025_paper.html ; https://arxiv.org/html/2505.02094v1
3. decMHT已有多个人形搬运与单机到多机迁移，冻结的是低层行走策略，上层产生上肢关节目标及行走指令。https://arxiv.org/html/2609.17824v1
4. HA-DiPO已有异构腿式协作搬运、分层和CTDE；异构+分层本身不是充分创新点。https://arxiv.org/html/2610.33584v1
5. FiLM是已有仿射特征调制方法。https://ojs.aaai.org/index.php/AAAI/article/view/11671

## 已知代码事实

- PPO std为每动作维度全局参数；推理用均值。std变化不是状态相关置信度。
- Stage2恢复后std设为0.45是人为干预；归一化器也会继续更新。
- 任意重置参考帧都有共同初始化噪声；step-zero仅是根部位置/姿态的额外配置覆盖。
- 当前目标来自动作末帧；目标版本控制一次性成功奖励；参考片段结束可能重采样而不终止整个episode。
- movebox目录包含一条reframed动作及镜像；没有当前checkpoint rollout性能证据。
- 直接读取两条npz：各325帧、50Hz、首末样本相距6.48秒；箱体中心初始/末帧/最大高度约0.184/0.183/0.845米。证明演示包含放下阶段，不证明策略不能持续持箱。
- 全序列按箱体平面速度>0.1m/s筛选，各192帧；相对机器人根部yaw的运动方向均在前半平面，约82.8%在正前方±45度。没有接触分段，不能称为持箱能力测试。原始统计和哈希在sources/motion_coverage.json。
- 当前接口以单机器人dof/root状态为中心；环境复制不等于两个机器人共享同一箱体。

## 禁止主张

不能声称已证明安全/稳定、std测量了违反程度、无关节输入保证构型无关、冻结参数意味着FiLM后函数未改变、单条动作已涵盖全向搬运、方案首创或达到录用标准。不能把数据集运动统计当作策略能力。

## 假设与未决项

待检验：条件偏移与物理失败是否关联；能力测量是否能预测双机组合失败；受限调制是否扩展可用范围；高层能否跨独立低层复用。用户已确认两台Unitree G1及RSS2027第一轮投稿目标；算力、具体末端配置及实机接触感知尚未确认。所有理论只在明示局部模型与误差界条件下成立。
