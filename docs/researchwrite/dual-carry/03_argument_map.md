# 论证架构

## 科学张力

单机交互策略已经会搬箱，却不因此具备可任意组合的控制接口。高层命令和伙伴力改变状态分布、接触几何与时间尺度；无限制微调可解决部分问题，却破坏冻结复用的假设。

## 中心问题

在固定低层参数与明确输入接口下，测得的带接触上下文的局部能力范围能否预测同构双机协作失败，并改善共享物体目标的协调？未见伙伴是扩展验证，未见构型组合是资源允许后的条件性扩展。

## 假设

失败不仅由参数遗忘或动作探索尺度造成，动态命令不匹配和闭链力学不相容是可独立测量的因素；基于局部能力和共同物体运动约束的协调可能优于直接目标追踪与仅KL限制。

## 支撑链

1. 用固定输入KL、独立访问分布与物理指标分离变化来源，再用干预检验影响。
2. 测量单机可恢复范围、指令带宽和外力耐受，识别严格冻结的能力上限。
3. 辨识实际低层指令到物体运动/接触响应的映射，再约束共同物体运动与指令变化率；先同构验证，再逐步加入未见伙伴和异构。

## 实施门槛

- G0：当前 checkpoint 能否持续持箱并响应慢变目标；不能以末帧到达替代。
- G1：按接触模式、时间窗和概率阈值定义的经验能力范围，在伙伴扰动留出集上是否仍校准。
- G2：真实共享刚体的同构双机仿真中，联合约束方法是否超过简单低通/限速基线。
- 严格冻结 Actor、归一化器及动作映射为主线；冻结主干加 FiLM 是独立扩展，不共享“控制函数不变”的假设。

## 反证

如果简单低通和慢速MPC同样有效，复杂FiLM或学习协调不是必要；如果能力模型对伙伴扰动不能校准，不做安全证书声明；如果严格冻结无法完成角色所需动作，明确需要离线扩展技能，而不是归因高层优化失败。

## 预期认知贡献

给出可复现的“何时可组合、何时必须改低层”的边界和有对照的协调方法，允许结论为负。
